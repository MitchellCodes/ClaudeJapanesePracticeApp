# N5 Practice

An installable PWA for practicing Japanese up to JLPT N5: hiragana, katakana, 95 kanji and ~300 words.

- **Library**: browse everything with romaji and English. Tiles are colored by your success rate (gray = new, red to green as you improve).
- **Flashcards**: flip through cards freely. Never touches your stats.
- **Game**: endless four-choice quiz in both directions, with score and streak. Weak and unseen items appear more often.

Progress is stored on-device only. Storage sits behind the `StatsRepository` interface in `src/stats/`, and `mergeStats` does per-item last-write-wins, so cloud sync can be added later without touching the UI.

## Develop

```bash
npm install
npm run dev      # dev server
npm test         # unit tests
npm run build    # production build into dist/
npm run preview  # serve dist/ locally
```

The build uses base path `/ClaudeJapanesePracticeApp/` (GitHub Pages). Override with `BASE_PATH=/ npm run build` for a root-hosted site.

## Deploy to GitHub Pages

In the repo settings, set Pages source to **GitHub Actions**. Pushing to `main` runs `.github/workflows/deploy.yml`, which tests, builds and publishes `dist/`.

## Install

Open the deployed site in Chrome or Edge (Windows 11) or Chrome (Android) and use the **Install app** button or the browser's install option.

Icons are generated by `npm run icons` (`scripts/make-icons.mjs`).
